# OpenQuest trademark policy

This policy protects the identity of the official OpenQuest network without
restricting compatible implementations or truthful descriptions.

You may use the OpenQuest name without case-by-case permission for accurate
statements such as:

- Built with OpenQuest
- Powered by OpenQuest
- OpenQuest-compatible
- Implements the OpenQuest protocol
- Forked from OpenQuest

These uses must not imply endorsement, partnership, or official status.

Permission is required for uses that would reasonably imply an unofficial
network is official, including:

- using OpenQuest as the primary name of another hosted service;
- using the official logo as another service's main logo;
- calling a fork “Official OpenQuest”;
- using branding that implies partnership or endorsement; or
- using confusing domains intended to impersonate the official network.

The trademark policy protects identity, not interoperability. The Apache-2.0
software license does not grant additional rights to OpenQuest names or logos.
